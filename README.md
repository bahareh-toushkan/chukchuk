# 척척 조달관

2026 조달청 AI 게임·콘텐츠 공모전 · AI 게임 부문 출품작

바로 하기: 이 저장소의 GitHub Pages 주소를 열면 브라우저에서 바로 실행됩니다. PC와 휴대폰 모두 됩니다.


## 실행 방법

1. 이 폴더의 index.html 파일을 더블클릭합니다.  
2. 웹 브라우저(크롬, 엣지 등)에서 게임이 바로 열립니다.  
   설치와 인터넷 연결이 필요 없습니다.  
   (브라우저가 열리지 않으면 index.html을 크롬이나 엣지 창으로 끌어다 놓으세요.)  

## 조작

마우스 클릭 또는 화면 터치만 사용합니다. 한 판은 약 3~4분입니다.  
소리는 화면 오른쪽 위 단추로 끄고 켤 수 있습니다.  

## 내용

하루 동안 조달관이 되어 다섯 가지 일을 합니다.  
1. 나라장터 - 공정하게 비교하기  
2. 납품 검사 - 납품 전에 꼼꼼히 검사하기  
3. 혁신제품 - 첫 구매자가 되어 주기  
4. 원자재 비축 - 모아 두고, 필요할 때 풀기  
5. 해외 진출 - 우리 기업과 세계를 잇기  

## 정책 내용의 출처 (2026. 11. 13. 확인)

1. 나라장터: 조달청 누리집 「나라장터 연혁」 https://www.pps.go.kr/kor/content.do?key=01230  
2. 납품 검사: 조달청 조달품질원 누리집 「품질관리제도」 https://www.pps.go.kr/center/content.do?key=00289  
3. 혁신제품 시범구매: 조달청 누리집 「혁신제품」 https://www.pps.go.kr/kor/content.do?key=00648  
4. 비축: 조달청 비축물자 누리집 https://www.pps.go.kr/bichuk/index.do  
   조달청 보도자료(2023. 9. 13.) 「공급망 위기 대응력 확보 위해 공공비축 강화」  
5. G-PASS: 조달청 누리집 「G-PASS 지정제도」 https://www.pps.go.kr/kor/content.do?key=00714  
   「조달사업에 관한 법률」 제28조
